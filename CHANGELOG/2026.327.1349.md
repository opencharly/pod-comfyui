# 2026.327.1349 — fix(runtime): release VRAM after five idle minutes, and install the Manager package

## Summary

Two launch-time defects on the running pod, both measured live, fixed together because they are one
concern (what the pod does with the card and with its own optional machinery at runtime):

**1. The pod never released VRAM.** ComfyUI keeps every loaded model resident by design — Dynamic
VRAM, and this candy deliberately does not pass `--disable-smart-memory` — so an idle pod held
**11,840 MiB of a 16,376 MiB card** with an empty queue, which is what starved
`check-strata-gpu-pod` (opencharly/pod-strata#6). `POST /free {"unload_models":true,"free_memory":true}`
released it to **402 MiB in 3 s**, and the next generation reloaded and returned HTTP 200.

- `idle-unload.sh`, launched by `start-comfyui.sh` in its own session (the model-set-fetch pattern),
  posts `/free` once after `COMFYUI_IDLE_UNLOAD_SECS` (default **300** = five minutes; `0` disables)
  with an empty queue and no new `/history` entry, logs the release to the state volume, and
  re-arms on the next prompt.
- New runtime check `comfyui-idle-unload` runs after `comfyui-vram-offload` (which leaves the
  checkpoint resident) and requires the server's own `vram_free` to **recover** — a check that only
  asserted `200` would pass over a server that answers and releases nothing.

**2. The UI demanded "Please upgrade ComfyUI-Manager to version 4.2.1 or higher".** The launcher
passes `--enable-manager`, but the `comfyui-manager` PACKAGE was never in the pixi environment — its
dependency block was there and the package was the missing half. `main.py` therefore disabled the
flag, `/api/manager/version` answered **404**, and the frontend's Nodes Manager showed that prompt
on every page.

- `pixi.toml` pins `comfyui-manager = "==4.4.2"`; `pixi.lock` regenerated (`+ comfyui-manager 4.4.2`,
  `nh3`, `uv`).
- New build check `comfyui-manager-version` asserts the package is importable and at least 4.2.1 —
  the version the Nodes Manager requires.
- The legacy `custom_nodes/ComfyUI-Manager` clone stays absent (`comfyui-legacy-manager-absent`).
