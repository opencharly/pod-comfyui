## Summary

Replace `SaveImageAdvanced` with `SaveImage` in the four shipped image API workflows
(Qwen-Image-2.1 Turbo T2I, Qwen-Image-Edit-2511 Lightning, Z-Image-Turbo int8,
Z-Image-Turbo bf16). Each file changes by exactly ONE node line; there is no
reformatting. The `env_provide` base64 transport values are regenerated from the
committed files. The fifth API workflow (`wan2.2-5b-ti2v.api.json`) uses
`SaveVideo` and is unchanged.

`bit_depth`/`input_color_space` inputs are rejected. `SaveImage` has no such
sub-inputs and is one of the output classes Open WebUI already collects; the
bundled templates use it.
