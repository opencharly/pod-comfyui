# 2026.290.1729 — fix(comfyui): advance the layer-cuda pin past the Arch gpgcheck fix, and the nvidia pin with it

## Summary

**This is one link of a transitive pin cascade, and it is the link that reddens every bed in the CachyOS GPU chain.**

`charly.yml:12` pinned `layer-cuda:v2026.274.0643`. That `cuda` candy in turn pins `layer-nvidia:v2026.271.1817` — the pre-`#12` tag whose gpgcheck step asserts `stdout: "gpgcheck=1"` against `/etc/dnf/repos.override.d/99-config_manager.repo`, a file that cannot exist on an Arch-family arm. `layer-nvidia#12` moved that assertion into the command so the Arch arm can skip honestly; a consumer must therefore pin a `layer-cuda` whose own nvidia pin is that fix.

Because a candy's `check:` steps run in the **`check-image` phase of every box that composes it**, this one stale transitive pin fails *every* bed in the tree. Measured on the GPU-free bed `check-strata-pod`: **39 of 40 steps pass**, and the single failure is this probe.

This advances `layer-cuda` to `v2026.290.1513` (i.e. `layer-cuda#16`'s merge, tagged at merge time; its own `layer-nvidia` pin is `054aa7702ebe…` = `layer-nvidia#12`).
